# Ready to Sail v1

Static frontend prototype for the Ready to Sail operational readiness platform.

Modules included:
- Command Center
- Crew Changes
- Crew
- Documents
- Fleet
- Routes & Ports
- Ready AI
- Reports

## Local preview

Open `index.html` directly or run:

```bash
python3 -m http.server 8066
```

Then visit `http://127.0.0.1:8066/`.
